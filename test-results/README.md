# Результаты тестирования

## Проверенные окружения

| Окружение | Результат |
|---|---|
| Ubuntu в WSL | 12 тестов пройдено |
| Windows, запуск через CMD и `.bat` | 11 тестов пройдено |
| MSYS2, Bash 5.2.37 и GNU tar 1.35 | 12 тестов пройдено |

Результаты Ubuntu/WSL и Windows зафиксированы по итоговому выводу тестов. Текстовые протоколы ниже относятся к отдельным локальным прогонам в указанных для них окружениях.

## Текстовые протоколы

| Файл | Содержимое |
|---|---|
| `bash-msys2.txt` | Локальный MSYS2-прогон: 12 тестов, включая регрессионные проверки |
| `windows.txt` | Локальный прогон Windows-версии: 11 тестов |
| `smoke.txt` | Справка, параметры по умолчанию, синтаксис и дополнительный скрипт |

Windows-протокол и smoke-проверки получены 17 октября 2026 года. MSYS2-протокол обновлён 20 октября 2026 года по московскому времени.

## Состав проверок

В шести положительных сценариях создаются четыре файла по 128 МиБ, всего 512 МиБ. Ошибочные сценарии используют неизменённую папку того же размера. Проверяются выбор старых файлов, граничные значения порога, gzip/LZMA, распаковка, SHA-256, итоговый размер и очистка блокировки.

Bash-набор содержит дополнительную короткую проверку известного SHA-256 для необычных имён и обнаружения изменения содержимого. В LZMA-сценарии моделируется команда `lzma`, создающая XZ, после чего проверяется создание настоящего LZMA при явном выборе формата.

Проверки ссылок на внешние папки подтверждают отсутствие перехода по symlink/junction. В Bash дополнительно моделируется отказ архиватора с кодом 42: исходные данные должны сохраниться, итоговый архив не должен появиться.

Временные абсолютные пути в протоколах относятся к соответствующим запускам и не используются в конфигурации проекта. MSYS2 и Ubuntu/WSL являются разными окружениями. Отдельный прогон в Linux-VM с самостоятельной установкой ОС не включён в перечень выполненных проверок.
