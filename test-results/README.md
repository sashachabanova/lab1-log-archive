# Фактическая проверка

Windows-протокол и smoke-проверки: 17 октября 2026 года. Bash-протокол обновлён 20 октября 2026 года (московское время) после исправления проверки контрольных сумм. Протоколы сохранены после реальных запусков.

| Протокол | Окружение | Результат |
|---|---|---|
| `bash-msys2.txt` | Bash 5.2.37, GNU tar 1.35, GNU-утилиты, MSYS2 на Windows | 12 тестов прошли |
| `windows.txt` | Windows PowerShell 5.1, штатный Windows tar/bsdtar | 11 тестов прошли |
| `smoke.txt` | Проверка аргументов по умолчанию, справки, синтаксиса и дополнительного задания | Результаты приведены в файле |

В обновлённом Bash-наборе перед 12 полными сценариями есть быстрая регрессионная проверка хеширования необычных имён и обнаружения изменения содержимого. Её результат обозначен `CHECK`, отдельно от счётчика лабораторных сценариев.

В LZMA-сценарии дополнительно воспроизводится компрессор `lzma`, создающий XZ вместо LZMA. Контрольный XZ-архив отвергается LZMA-проверкой, а основной скрипт в том же окружении успешно создаёт настоящий LZMA через явно выбранный `xz --format=lzma`.

В шести положительных сценариях каждой версии записывалось по четыре файла 128 МиБ. Каждый ошибочный запуск также имел входную папку с 512 МиБ. Тесты проверили данные после распаковки и оставшиеся оригиналы по SHA-256. Отдельно проверены ссылки на внешние папки; в Bash — также контролируемый отказ архиватора с кодом 42.

Windows-реализация запускалась именно через `.bat`, не только прямым вызовом функции PowerShell. Для LZMA проверены выбранный формат и восстановимое содержимое.

MSYS2 предоставляет Bash и GNU-утилиты поверх Windows. Это полезная реальная проверка Bash-скрипта, но **не отдельный прогон в Linux-VM**. На этой машине WSL-дистрибутив не установлен. Перед сдачей нужно повторить `bash test_log_archive.sh` в учебной виртуальной машине.

Для локальной проверки Bash использовались пакеты из официального репозитория MSYS2: https://repo.msys2.org/msys/x86_64/ . Они установлены в отдельной служебной папке за пределами выдаваемого проекта и в архив для группы не входят. Системная установка Linux/VM не выполнялась.

В протоколах содержатся временные абсолютные пути конкретного прогона; они не нужны для последующего запуска на другом компьютере.
